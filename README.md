# My static website

The agent reads [AGENTS.md](AGENTS.md) for workflow instructions and
[design.md](design.md) for visual criteria and site decisions.

This repository contains your site and its checks. It is independent of the tool
that created it. Sample information is fictional.

1. Open this folder with File > Open Folder in VS Code.
2. Open Codex and say: "Resume my site with workshop-maintenance."
3. Prepare dependencies with npm.cmd ci --ignore-scripts.
4. Preview with npm.cmd run dev at http://127.0.0.1:4321.
5. Prepare Chromium with npx.cmd --no-install playwright install chromium.
6. Run npm.cmd run verify.
7. Read evidence/report.md. A failure blocks publication.

Publication/maintenance: [English guides](docs/en/README.md). Significant changes
must be reclassified. Opening this folder does not upload information or contract
services. Licensing must be agreed with the owner; no open-source license is
automatically granted.
