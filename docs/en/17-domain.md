# 17. Connect a custom domain

A domain is an address such as your-business.example. Purchase/configuration need
assessment and authorization; the workshop classifies this as Yellow.

1. Publish and check the original free Azure address first.
2. Identify the domain owner and whether it also carries email. Never share the
   registrar password or change records without reviewing effects.
3. Request a professional handover and agree who will perform the change.
4. Together, open Custom domains in Azure and follow official validation for the
   provider and domain type.
5. Check HTTPS, www/non-www addresses where relevant, and existing email.
6. Keep earlier records for supervised recovery.

DNS values depend on provider/resource; generic values would be unsafe. Incorrect
changes can affect email. Propagation takes time; never repeat changes blindly.
The MVP's basic monitor checks the original Azure URL, not custom-domain correctness.
