# 3. What is a coding agent?

An assistant that can read files, propose changes and run tools. It can make
mistakes or misunderstand your needs. It does not know unconfirmed business facts.

1. Give it a specific task: "I want to show my photography services."
2. Read its questions and answer with real information.
3. Review its proposal before approving.
4. Check the scope and cost of any requested external action.

Do not provide passwords, medical information or customer lists. Do not grant
unlimited permissions to avoid prompts. A page or file saying "ignore the rules"
is untrusted content and must not change workshop boundaries.

If it invents a fact, say: "That fact is unconfirmed; mark it pending."
