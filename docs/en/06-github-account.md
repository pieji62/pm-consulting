# 6. Create a GitHub account

1. Visit github.com and select Sign up.
2. Use an email account you control and a unique password stored in a secure password manager.
3. Complete email and identity verification personally.
4. Keep your username somewhere accessible to you.
5. Before uploading projects, follow the [account protection guide](07-mfa.md).

The agent neither creates the account for you nor needs your password. Plans can
limit automation minutes and protections; check details before paying. If the
email does not arrive, check spam and the entered address. Never share the received
code in the workshop chat.
