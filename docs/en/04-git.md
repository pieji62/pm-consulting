# 4. What is Git?

Git stores versions of files. A **commit** is a save point with an explanation.
Saving in Git does not itself publish your website or upload files.

1. Ask: "Show me what changed and prepare a local save point."
2. Check that the explanation matches your request.
3. Keep versions before and after important changes.
4. To recover work, describe which version worked. Do not delete folders.

VS Code's Source Control shows changes. Ask for a summary and preview rather
than interpreting code. If a conflict appears, stop and get help. Never paste
deletion or history-rewriting commands without understanding their effects.
