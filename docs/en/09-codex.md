# 9. Sign in to Codex

1. In VS Code Extensions, find the official Codex extension published by OpenAI.
   Its verified identifier is openai.chatgpt; avoid imitations.
2. Open its icon, or use the command palette's Codex: Open Codex Sidebar.
3. Follow the sign-in option available to your account and complete it in the
   official browser page. Do not paste keys into site files.
4. Check your account plan and limits. The workshop includes no subscription and
   does not require buying API access to run its local scripts.
5. Open the workshop folder and say: "I want to create my site with workshop-discovery."

If sign-in fails, check your account, network and organization restrictions.
Unlimited permissions are not a solution. Test actual compatibility on the seminar
computer; this sign-in journey has not been validated on a clean installation.
