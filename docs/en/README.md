# Your workshop guide

You do not need to learn programming to follow this journey. You know your business;
the agent proposes and carries out tasks. You review facts and decide when to publish.

**We do not know what we do not know.** An attractive page can contain errors.
Tests reduce some risks; they do not guarantee security or legal compliance.
