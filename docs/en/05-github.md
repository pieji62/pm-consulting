# 5. What is GitHub?

GitHub stores a copy of a project in an account and can run checks.
A **repository** is the project folder together with history and configuration.

1. Keep the workshop tools repository private.
2. Create a separate private repository for each business site when you choose to upload it.
3. **Code** shows files, **Actions** shows checks and **Pull requests** shows proposed changes.
4. A private repository can still produce a public website on Azure.

The account owner controls file access. Protect the associated email account too.
If a project is missing, check which account you signed in with; do not make a
public copy as a workaround.
