# 10. Create your first site

1. Open the product/kit folder in VS Code and run npm.cmd start.
2. Tell Codex: "Use workshop-discovery. I want a website for my business. Ask questions
   in English, a few at a time. Do not publish anything yet."
3. Answer and review requirements. The agent saves progress in its own folder,
   such as projects/my-site, without changing other projects.
4. If Yellow or Red appears, read the explanation. You can consciously remove a
   feature or request a professional handover report. Never ask to bypass the limit.
5. Personally approve requirements and then the proposal when each revision is
   displayed. [Guide 12](12-approval.md) explains how.
6. The agent generates the site. Open its folder in another VS Code window to continue.
   You do not need another account or another AI service.
7. Ask: "Show me the preview and run verification."

You can pause and return another day. Say: "Resume from saved state." Inside the
site, the agent uses npm.cmd start -- status . . If state is missing, confirm the
open folder; never generate over the existing site.
