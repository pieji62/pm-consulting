# 2. What is VS Code?

Visual Studio Code is the workspace where you open the site folder and talk to Codex.
You do not need to edit code directly.

1. Open Visual Studio Code from Windows Start.
2. Choose **File > Open Folder...** and select the workshop folder.
3. Trust the folder only when it comes from the instructor's reviewed package.
4. **Explorer** shows files; the Codex icon opens the conversation.
5. **Terminal > New Terminal** opens the place where commands run.

If the wrong folder is open, use Open Folder again. Avoid opening your entire
personal folder: the agent should work on this project, not unrelated documents.
