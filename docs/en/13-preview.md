# 13. Preview your site before publishing

1. Open the generated site folder.
2. Ask the agent to run npm.cmd run dev.
3. Open http://127.0.0.1:4321 in your browser. This is your computer's address,
   not the public address you will share with customers.
4. Try every page and narrow the browser window.
5. Request specific changes: "More space between sections" or "A shorter heading."
6. To stop previewing, select its terminal and press Ctrl+C.

If the browser cannot connect, check that the command is still running. If a port
is busy, ask the agent to close its earlier preview or report the new port.
Content and significant changes need a new requirements revision. Development
preview does not apply every Azure header; tests use a local server that does.
